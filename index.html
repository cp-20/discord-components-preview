Message Preview for Discord

Renders a Discord message payload (content, embeds, components, Components V2) like the Discord client and shares it as a link: https://discord.cp20.dev/#p3=<base64url(deflate-raw(JSON, dictionary))>.

AI agents: the full link algorithm, the compression dictionary, every supported format and ready example links are in /llms.txt. Human docs: /docs. Examples: /gallery.
